Handheld Save Sync

Handheld Save Sync is a small personal tool used by one family to back up and sync video game save files between their own Android handheld gaming devices.

It uses the open-source rclone program to copy emulator save files to and from a folder in the user's own Google Drive. It only requests access to files and folders that it creates itself (Google's drive.file permission); it cannot see or change anything else in the user's Drive.

This is not a public service and is not offered to anyone outside the family.
