Privacy Policy – Handheld Save Sync

Last updated: November 3, 2026

What the app accesses

Handheld Save Sync requests only Google's drive.file permission. With it, the app can create, read, update and delete only the files and folders it has created itself in the signed-in user's Google Drive. It cannot see or access any other files, photos, documents, email, contacts or other Google account data.

What data is stored, and where

The only data the app handles is video game save files from the user's own handheld devices. These are copied directly between the device and the user's own Google Drive. The app has no server: no data is sent to, collected by, or stored by the developer or any third party.

Sign-in credentials

The Google sign-in token is stored only on the user's own device, in a location other apps cannot read, and is used only to sync the save files described above.

Sharing and selling

No data is shared with, sold to, or used for advertising by anyone.

Removing access

Users can revoke the app's access at any time at myaccount.google.com/permissions, and can delete the app's folder from their Google Drive.

Google API Services User Data Policy

Handheld Save Sync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
